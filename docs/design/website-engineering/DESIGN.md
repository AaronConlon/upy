# upy 官网：工程制图

用户已选择方向 A。北极星：用工程图纸的秩序承托滑板 Gopher 的动势，让发布路径一眼可读。

## 用户任务与结构

面向准备在 Linux / macOS 服务器部署 Web 项目的开发者。主要动作是安装 upy，其次是阅读配置和部署方法。保留真实命令、下载和文档入口，沿用现有 HTML / CSS / JavaScript 与 GitHub Pages。

## 视觉决定

- 保留 Go Gopher 与 Go 蓝；背景为冷白 `#f5f7f6`，文字石墨色 `#172b33`，强调色 `#006e87`。
- 原有圆角色块改为细网格、辅助圆、定位十字和标注线。辅助线只出现在角色图纸区与部署流程中，不铺在正文下。
- Space Grotesk 标题、IBM Plex Sans 正文、JetBrains Mono 命令与标注；中文使用系统中文字体回退。
- 标题 48–78px、正文 15–18px，按钮最小高度 44px。小字号只用于工程标注、平台信息和图注。
- 矩形按钮、统一 1px 分隔线；布局为角色展示、安装入口、串联部署步骤、收尾文档入口。
- 复用项目 Logo，不生成新素材。工程标注为品牌展示语法，不代表实际尺寸或产品性能数据。

## 动效

GSAP 3.15.0 与 ScrollTrigger 本地托管，保留上游许可证。

1. 首屏辅助线及十字依次显现，0.35–0.6 秒。
2. Gopher 水平滑入并轻微扶正，0.85 秒；标题位移 22px 入场。
3. 内容进入视口时位移 22px 出场；流程线随滚动延伸，节点跟随阅读进度激活。
4. 按钮 hover 位移 2px，按下回落 1px，复制按钮保留成功与失败反馈。

使用原生滚动，无 pin、滚动劫持或持续循环。减少动态效果模式不创建动画与 ScrollTrigger。脚本不可用时正文仍默认可见；pagehide 清理，bfcache 恢复时重建。

## 验收

检查 320 / 375 / 414 / 768 / 1440px；复制成功、拒绝权限后的手动复制；动态偏好切换；脚本不可用；流程线滚动进度；桌面与手机截图及 2 倍细节。独立视觉评审与结果见 REVIEW.md，取证文件见 evidence/。

## 减法

删除原有英文口号眉标、READY TO ROLL 贴纸和重复引导句，保留必要的步骤编号、平台信息与命令说明。中文界面中的英文仅保留工具名称、命令、文件名及工程图注内的 Go Gopher。

## 评审后修订

- 首屏图注改为 `Release / Bundle → upy → 服务器`，直接交代输入、工具和目标。
- 删除“品牌标识 / 正视图”“01 — Go Gopher”“轻装上阵，发布向前。”及重复的收尾眉标；移除无测量意义的右侧尺寸线。
- 日常维护段改为通栏命令索引，打破连续左右分栏。
- 区块入场设置 `immediateRender: false`，未进入视口的正文保持可见；即使直接截整页、跳到页尾，也不会留下预先隐藏的空白。
- 工具仍提示章节眉标与步骤编号：保留，因为它们承担章节定位和真实流程顺序，不是装饰口号。

最终减法：删除顶部重复分类、图纸右上 Go / upy、向下探索与页脚口号；手机将发布路径置于角色图上沿，提升至 14px 并使用浅蓝底。

GSAP 用法依据：https://gsap.com/docs/v3/GSAP/gsap.matchMedia()/ 与 https://gsap.com/docs/v3/Plugins/ScrollTrigger/ 。
