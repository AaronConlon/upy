# 验证记录

日期：2026-10-19。使用真实 Chromium 浏览器验证，无生产构建与全量业务测试。

## 交互与动画

- 桌面依次打开页面、点击“开始部署”、复制安装命令、读取剪贴板并滚动到第二步，连续 3 次通过。
- 3 次滚动中流程线进度均大于 0.15，确认滚动叙事实际生效。
- 动态切换 `prefers-reduced-motion: reduce` 后，ScrollTrigger 数量为 0；恢复偏好后重新创建。
- 阻断 `vendor/*.js` 后，标题和复制入口仍可见。
- 模拟 Clipboard 权限拒绝后，显示手动复制提示，选中内容与完整安装命令一致。
- 手机 200% CSS 放大检查了文字重排与操作入口，页面无横向溢出；这与取证工具的 2 倍像素密度截图分开验证。
- 320 / 375 / 414 / 768 / 1440px 下页面宽度与视口一致，图片正常加载。
- JavaScript 语法检查及 Git diff 空白检查通过。

## 工具限制与人工判断

取证环境缺少 ffmpeg，因此没有 MP4，仅留下出场与滚动采样帧，未完成正常速度视频回看。取证工具在一次动作滚动之后再次探测全页滚动时未检出变化；同一报告的 steps 项已检测到流程线约 768px 的尺寸变化及区块出场。另用真实浏览器读取 GSAP 流程线进度，确认滚动驱动已生效，不将该提示当作运行结果通过。

独立评审发现第一版手机长页末尾空白：该证据没有滚动到全部区块，暴露出提前隐藏视口外正文的问题。已改用 `immediateRender: false`，并重截无需滚动的完整长页核对。

修订后补验：未进入视口的第三步计算 opacity 为 1；手机第三步命令列表和收尾内容均显示。最终截图见 `delivered/`，两轮评审意见和修订记录见 REVIEW.md。
