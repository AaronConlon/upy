# 独立视觉评审记录

## 第一轮：7 / 10

独立评审者仅查看首屏、长页和动画采样帧，不读取代码。

主要问题：手机长页后半段出现未显现区块；首屏图纸只围绕 Gopher 而没有解释部署关系；下半页左右分栏重复。

处理：入场动画改为 `immediateRender: false`；首屏加入 `Release / Bundle → upy → 服务器`；移除无信息的右侧尺寸线、重复图注和收尾眉标；日常维护改为通栏命令索引。重新验证手机第三步和收尾内容完整显示。

## 第二轮：8 / 10

另一位独立评审者查看修订后的桌面与手机首屏、长页，不读取源码，不获知上一轮分数。

主要意见：工程制图方向成立，Gopher 与细线网格具有辨识度；手机首屏的部署关系仍在图框下方，桌面路径文字的权重偏低；有少量重复口号。

最终调整：手机将发布路径放在图纸上沿，路径字号升至 14px、使用浅蓝底；删除顶部重复分类、Go / upy 图注、向下探索提示和页脚口号。保留真实步骤编号及四处章节标记，服务导航和顺序。

第二轮后的微调由主 Agent 检查，未再次独立打分。8 / 10 是第二轮送审版本分数，不作为最终版本的新评分。

独立评审只验证截图视觉；交互、减少动态效果、脚本降级与滚动进度由主 Agent 使用真实浏览器验证，见 QA.md。环境缺少 ffmpeg，没有生成 MP4，动效仅有采样帧与运行时验证，未完成正常速度视频回看。
