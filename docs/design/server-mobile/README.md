# upy server 移动端设计稿

浅色、理性线条、设计院制图语汇：细线分隔、直角结构、冷白灰背景、等宽技术信息，绿色 / 赭红只表达执行状态。所有图标为本地 Lucide SVG，线宽 1.5px，无 emoji，无 CDN 依赖。

## 文件

- `index.html`：三屏设计展板，可直接用浏览器打开。
- `?screen=overview`：服务总览。
- `?screen=project`：项目详情。
- `?screen=logs`：部署日志，支持复制任务 ID 和导出示例日志。
- `preview.png`：三屏总览；`overview.png`、`project.png`、`logs.png`：390px 单屏长图。
- `tokens.css`：本设计稿独立 tokens，不修改官网样式。
- `vendor/`：Lucide 原始 SVG 与 LICENSE。

## 范围

这是独立设计原型，未改动 Go server UI、认证或接口。所有主机名、版本、运行时间、项目状态和日志均为演示数据。原型主路径为总览 → microdraft 项目 → 部署日志；其他项目列表用于状态展示。

现有 server 已支持 TOTP 验证、health、项目列表、部署任务、日志列表和详情。总览聚合、当前版本与服务单元信息是建议扩展的展示字段，落地时需要确认并补齐数据来源；“已部署”表示部署任务结果，不等同于应用实时健康监测。当前稿未包含登录 / TOTP 验证页。

## 验证

使用 Playwright 检查 320 / 375 / 390 / 414 / 768px 的三个页面，无横向页面溢出。主路径跳转及示例日志导出正常。展板内可纵向滚动；独立页面按内容自然延伸。
