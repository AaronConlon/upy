核心功能

部署、清理、备份与告警。

01 / 部署

从 Release 到生产，原子秒级切换。

在终端交互选择 GitHub Releases 资产包，或一行命令直接部署最新版本。 支持断点续传与 SHA-256 完整性校验；离线环境下支持本地 bundle 文件。

查看部署指南 ↗
部署命令 
# 交互选择 Release 资产
upy release

# 部署最新正式版
upy release latest

# 部署本地 bundle 文件
upy bundle ./bundle.zip
SPA 静态站点

原子软链切换，自适应权限规整。

解压至独立版本目录，通过 current 软链原子切换。 自动将目录与文件规整为 0755/0644 权限，避免 Nginx / Caddy 出现 403 权限错误。

原生 Systemd 服务

Go 二进制原子纳管，拒绝静默提权。

纳管 Go/Rust 等轻量常驻进程。 严格预检运行账号与权限，启动参数原样保真，端口身份严密防伪，失败秒级自动回滚。

Docker / Compose 容器项目

平滑启停，失败自动回滚。

新版本镜像与配置就绪后再停止旧容器并释放端口，避免端口冲突。 内置健康检查机制，启动异常时自动回滚至上一可用版本。

# 1. 交叉编译 Linux 纯静态二进制
- name: Build Go binary
  env:
    CGO_ENABLED: '0'
    GOOS: linux
    GOARCH: amd64
  run: go build -trimpath -ldflags "-s -w" -o bin/web ./cmd/web

# 2. 打包清单与可执行文件
- name: Package bundle
  run: |
    cat << 'EOF' > upy.yaml
    name: my-api
    version: ${{ github.ref_name }}
    type: system
    target: { os: linux, arch: amd64 }
    system:
      command: ["./bin/web", "--port", "8080"]
    healthcheck:
      url: http://127.0.0.1:8080/health
      timeout: 15s
    EOF
    zip -r bundle-linux-amd64.zip upy.yaml bin/web

03 / 备份

约定式数据备份，全流程加锁防护。

遵循约定优先原则，自动识别项目中的 backup.sh 脚本并注入环境变量。 执行期间自动施加跨进程排他互斥锁，严防并发写入产生脏数据；支持智能保留轮转策略与 Bark 移动端实时告警。

查阅备份与归档文档 ↗
01 / 约定备份脚本 零配置探测 backup.sh 
#!/usr/bin/env bash
# 环境变量由 upy 自动注入: UPY_BACKUP_DIR, UPY_PROJECT_NAME, UPY_TIMESTAMP
mkdir -p "${UPY_BACKUP_DIR}"
BACKUP_FILE="${UPY_BACKUP_DIR}/dump-${UPY_PROJECT_NAME}-${UPY_TIMESTAMP}.sql.gz"

# 在容器内安全执行 mysqldump 导出并压缩
docker compose exec -T db mysqldump -u root -p"${DB_PASSWORD}" "${DB_NAME}" | gzip > "${BACKUP_FILE}"

开源利器 什么是 Bark？
bark.day.app ↗

Bark 是一款针对苹果 iOS / iPadOS 设备的轻量、开源即时通知推送服务。只需要发送简单的 HTTP 请求，即可秒级将自定义通知推送至设备。upy 原生内建 Bark，提供零运维、即时响应的发布与备份观测能力。

01 / 统一配置结构 通用属性与多用户定义 deploy.yaml / ~/.upy/config.yaml 
# 统一写法：通用属性（对所有成员生效） + 用户级列表（按 - name 区分多用户）
notify:
  bark:
    # 1. 通用属性 (全局/项目默认继承)
    serverUrl: https://api.day.app     # 通用服务端节点 (可填自建私有域名)
    group: "payment-api"               # 通用推送分组
    sound: "chime"                     # 通用提示音 (如 bell, chime, glass 等)
    level: "active"                    # 通用时效级别 (active / timeSensitive)

    # 2. 用户级属性 (按 - name 区分多用户，字段优先级高于通用字段)
    users:
      - name: "前端负责人"
        token: "DEVICE_KEY_ALICE"
        sound: "glass"                 # 用户级覆盖通用 sound
      - name: "值班运维"
        token: "DEVICE_KEY_BOB"
        serverUrl: https://bark.ops.internal # 覆盖通用 serverUrl
        level: "timeSensitive"
      - name: "测试工程师"
        token: "DEVICE_KEY_CAROL"      # 未指定独立属性，完全继承通用配置
02 / 单人直配模式 极简开箱即用 deploy.yaml 
# 单人极简直配：直接在 bark 下声明 token 即可，完全继承通用设置
notify:
  bark:
    serverUrl: https://api.day.app
    group: "my-service"
    sound: "bell"
    token: "DEVICE_KEY_SINGLE_USER"
03 / 项目专属 Webhook 每个项目独立配置 · 无需全局配置 deploy.yaml 
# 项目级独立 Webhook（不污染全局，支持单 URL、多端点与 HMAC 签名）
notify:
  webhook:
    - url: "https://ops.example.com/api/deploy-webhook"
      secret: "SEC_KEY_FOR_HMAC_SHA256"  # 附带 X-Upy-Signature 防伪签名
      headers:
        X-Environment: "production"
    - url: "https://qyapi.weixin.qq.com/.../send" # 企微/飞书/钉钉群机器人
04 / 推送内容规范 全方位上下文自动组装 Title & Body 结构
