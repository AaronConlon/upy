安装

单行命令安装。

自动识别系统架构并配置 Shell Tab 命令补全。
单二进制零依赖，无后台常驻进程。

查看安装文档 ↗
安装脚本 
curl -fsSL https://raw.githubusercontent.com/AaronConlon/upy/main/install.sh | bash

默认安装至 /usr/local/bin，支持通过 INSTALL_DIR 指定安装路径。

核心功能

部署、清理与备份。

覆盖应用发布、磁盘空间维护与关键数据备份，构建单机运维闭环。

01 / 部署

从 Release 到生产，原子秒级切换。

在终端交互选择 GitHub Releases 资产包，或一行命令直接部署最新版本。 支持断点续传与 SHA-256 完整性校验；离线环境下支持本地 bundle 文件。

查看部署指南 ↗
部署命令 
# 交互选择 Release 资产
upy release

# 部署最新正式版
upy release latest

# 部署本地 bundle 文件
upy bundle ./bundle.zip
SPA 静态站点

原子软链切换，自适应权限规整。

解压至独立版本目录，通过 current 软链原子切换。 自动将目录与文件规整为 0755/0644 权限，避免 Nginx / Caddy 出现 403 权限错误。

Docker / Compose 容器项目

平滑启停，失败自动回滚。

新版本镜像与配置就绪后再停止旧容器并释放端口，避免端口冲突。 内置健康检查机制，启动异常时自动回滚至上一可用版本。

02 / 清理

磁盘空间分析与安全清理。

扫描项目磁盘占用（MB/GB），支持交互式清理历史 bundle 缓存与陈旧版本。 内置双重活跃版本保护，禁止删除 current 正在运行的版本；通过跨进程互斥锁避免并发冲突。

查看清理文档 ↗
清理命令 
# 交互式清理菜单（支持空间分析）
upy clean

# 清理历史 bundle 压缩包缓存
upy clean --bundles

# 仅保留最近 3 个历史版本
upy clean --keep 3
03 / 备份

约定式数据备份，跨进程互斥保护。

遵循约定优先原则，自动识别项目中的 backup.sh 脚本并注入环境变量。 备份期间自动施加排他互斥锁，确保数据一致性；支持保留份数轮转策略与 Bark 移动端通知。

查看常用命令 ↗
upy backup执行项目约定备份
upy release latest部署项目最新版本
upy clean --bundles清理历史 bundle 缓存
upy项目交互调度菜单
upy update检查并自升级工具
