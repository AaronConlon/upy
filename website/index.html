01 / Deploy

Atomic switching from Release to production.

Interactively pick a GitHub Release asset in the terminal, or deploy latest with a single command. Supports SHA-256 integrity verification, resumable downloads, and offline local bundles.

View deployment guide ↗
Deploy commands 
# Interactively pick a Release asset
upy release

# Deploy latest official release
upy release latest

# Deploy local offline bundle
upy bundle ./bundle.zip
SPA Static Sites

Atomic symlinks with automatic permission fixes.

Extracted into isolated release folders and switched atomically via the current symlink. Automatically standardizes permissions to 0755/0644 to prevent 403 Forbidden errors in Nginx and Caddy.

Native Systemd Services

Go binaries with atomic units and zero privilege creep.

Runs lightweight Go/Rust binaries under systemd supervision. Guarantees strict service user pre-checks, argument fidelity, port identity probing, and automatic rollback on failure.

Docker / Compose Applications

Graceful handover with automated rollbacks.

Prepares new images and configurations before stopping previous containers to prevent port conflicts. Includes built-in health checks that automatically rollback on startup failure.

06 / Server & Webhook

Background daemon, CI/CD inbound webhooks, and 2FA web console.

upy server runs as an ultra-lightweight background daemon. When CI/CD (GitHub Actions / GitLab CI) finishes a Release, it triggers an instant deployment via POST /api/v1/webhook/{project}—eliminating the need to expose VPS SSH private keys inside CI runners. Built-in TOTP two-factor authentication with 30-minute session cookies. Run upy server auth on the VPS to scan the enrollment QR code in the terminal; enrollment secrets are never served over HTTP.

View Server & Webhook docs ↗
01 / Inbound CI Trigger HMAC SHA-256 Verified .github/workflows/deploy.yml 
# GitHub Actions: Compute HMAC SHA-256 and trigger upy server on release
- name: Trigger upy deployment
  env:
    UPY_WEBHOOK_URL: "https://deploy.example.com/api/v1/webhook/my-api"
    UPY_WEBHOOK_SECRET: "${{ secrets.UPY_WEBHOOK_SECRET }}"
    TAG: "${{ github.ref_name }}"
  run: |
    payload='{"target":"'${TAG}'","force":false}'
    sig=$(printf %s "$payload" | openssl dgst -sha256 -hmac "$UPY_WEBHOOK_SECRET" | sed 's/^.*= //')
    curl -fsS -X POST "$UPY_WEBHOOK_URL" \
      -H "Content-Type: application/json" \
      -H "X-Hub-Signature-256: sha256=$sig" \
      -d "$payload"
