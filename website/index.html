开始使用 / 安装

先装上，再出发。

Linux / macOS 打开终端，运行安装脚本。
自动识别架构，并配置 Shell 命令补全。

查看安装选项 ↗
安装 upy 
curl -fsSL https://raw.githubusercontent.com/AaronConlon/upy/main/install.sh | bash

默认安装到 /usr/local/bin，必要时会请求 sudo 权限。

部署流程

发布，有一条清楚的路。

CI 负责构建和打包，upy 负责服务器上的部署。

01 / 关联项目

告诉它，项目在哪里。

在服务器的项目目录里放一份 deploy.yaml，关联 GitHub 仓库。私有仓库通过 upy init 配置 Token，支持按组织分别设置。

配置私有仓库 ↗
deploy.yaml · 服务器端 
name: my-app
release:
  provider: github
  repository: owner/my-app
  asset: bundle.zip
02 / 发布版本

选一个版本，然后上线。

从 GitHub Release 选择版本，或直接部署最新正式版。没有外网？传入本地 Bundle，同样可以部署。

构建产物里记得带上部署清单。

在项目目录运行 
# 交互选择 Release
upy release

# 部署最新正式版
upy release latest

# 直接部署离线包
upy bundle ./bundle.zip
静态站点

静态站点，原子切换。

SPA 资源安装到版本目录，通过 current 软链切换。让 Nginx 或 Caddy 指向它，后续发布沿用同一入口。

容器应用

容器项目，按流程交接。

准备新镜像、停止旧服务、启动新服务。配置健康检查后，检查失败会尝试回滚。服务器需预先安装 Docker。

03 / 日常维护

下次发布，少做几步。

成功部署后自动登记本地项目。之后在任意目录运行 upy，选择项目即可继续部署。也可以指定项目、清理缓存，或更新工具。

upy选择已登记的项目
upy deploy my-app部署项目最新版本
upy clean --bundles清理下载缓存
upy update更新 upy
